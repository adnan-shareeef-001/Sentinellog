# Security Policy

## Supported Versions
Only the latest release of SentinelLog receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
As a defensive security tool, we take security flaws in SentinelLog itself (e.g., Log Injection, ReDoS vulnerability in parsing regexes, path traversal in file ingestion, or XSS in HTML report generation) very seriously.

If you discover a vulnerability:
1. Please do **not** open a public GitHub issue.
2. Draft a clear description containing reproduction steps, sample malicious log lines, and affected components.
3. Submit your report privately to the maintainers or open a GitHub Security Advisory.
4. We will review and remediate within 48 hours.
